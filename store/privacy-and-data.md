# Privacy And Data Safety Answers

## Data Collected
- Email address: account creation, login, support.
- User role: client or supplier experience.
- Event details: type, date, city, guests, budget, place, comment.
- Supplier profile: name, city, category, price, phone, media, Instagram handle.
- User content: uploaded photos and videos.
- App activity: saved vendors, bookings, requests, reports, blocked vendors.

## Data Not Collected In Current App
- Precise location.
- Contacts.
- Health data.
- Financial information.
- Payment card data.
- Advertising ID.

## Data Sharing
Data is not sold. Supplier contact can open WhatsApp when the user chooses to contact a supplier. Email delivery is handled by SendGrid. Video/image links may load from remote media hosting.

## Security
Passwords are hashed with PBKDF2 on the backend. Auth uses bearer tokens. Email verification uses one-time six-digit codes.

## User Controls
Users can delete their account in the app or by using:
https://svadba.kz/account-deletion

Users can report or block suppliers from supplier profile pages.

## Apple App Privacy
- Contact Info: Email Address, used for App Functionality.
- User Content: Photos or Videos, used for App Functionality.
- User Content: Customer Support / Other User Content, used for App Functionality and Safety.
- Identifiers: User ID, used for App Functionality.
- Usage Data: Product Interaction, used for App Functionality and Analytics inside the app.
- Diagnostics: Not collected by the app directly.
- Tracking: No.

## Google Play Data Safety
- App collects personal info: Email address.
- App collects user content: Photos, videos, messages/comments/request details.
- App collects app activity: App interactions, saved vendors, bookings.
- Data is encrypted in transit when deployed behind HTTPS.
- Users can request data deletion.
- Data is not shared for advertising.
