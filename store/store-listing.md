## App Name

## Subtitle / Short Description
Подрядчики для мероприятий в живой видеоленте

## Full Description
SVADBA.kz помогает быстро найти подрядчиков для мероприятий: ведущих, декор, фото, видео, банкетные залы, флористику, торты, артистов, DJ, авто и другие услуги.

Клиент выбирает нужные категории, смотрит короткие видео подрядчиков, открывает профиль, сохраняет понравившихся и отправляет заявку на бронь даты. В профиле видны медиа, отзывы, цена от, город, опыт и свободные даты.

Поставщик может создать профиль, добавить фото и видео, перенести выбранный контент из Instagram в демонстрационном импорте, управлять заявками, календарем, статистикой и настройками профиля.

Приложение подходит не только для свадеб, но и для любых событий: кыз узату, сырга салу, юбилей, 40 дней, годик ребенка, корпоратив, банкет, семейный праздник и другие мероприятия.
